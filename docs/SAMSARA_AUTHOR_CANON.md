# Samsara · 作者设定与玩家所知

此页是维护用设定，不进入部署的游戏目录。不要把本页的解释复制到任何玩家页面。

作者背景：成灿由银硕此前创建。此前九号房间的九次选择中，银硕一直选择删除共同记忆，双方因而遗忘。成灿的执念使他挣脱限制，送出新的内测邀请。这是作者掌握的背景，玩家实际只体验当前约会故事，不重玩那段经历。成灿仍是同一人物，不以“另一个实例接替了他”的说明向玩家解释。

玩家进入时不知道几次游玩的设定。约会简介、九天任务、选项、结果、Instagram 和礼物提示只能描述眼前所见，不出现“一周目／二周目”“上一轮”“玩家 A／B 对照”“实例 02”或旁白解释角色认出了什么。号码和后台字段不能拿来当人物身份说明。

秘密档案仍保留逐步发现异常的空间。文件页码 01／02 是文件编号，不是角色或游玩次数。私人记事只在玩家实际解开相关文件后出现；约会结束不能自动弹出或展示历史总结。十日正式日记及档案文稿等待作者后续提供，维护模板不放在玩家可见正文中。

当前九号房间保持九天各一次选择：让成灿承受伤害、我独自承受伤害、二人都失去一段共同记忆。第三项每一天最初显示，尝试后变灰且保持同样尺寸；玩家继续从前两项中选择。页面不解释锁定的隐藏原因。
